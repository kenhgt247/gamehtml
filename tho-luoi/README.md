# Thỏ Lười Vượt Làng

Game chạy vô tận: chú thỏ lười đeo khăn rằn chạy qua làng quê Việt Nam, nhặt cà rốt, né chướng ngại và trốn Rùa đội nón lá.

- **Chạy vui**: chặng khó dần từ sáng tới đêm, combo, nhiệm vụ, tủ đồ.
- **Một chạm**: va là thua, đếm số chướng ngại vượt qua, có huy chương.

Toàn bộ game nằm trong `index.html`, không cần cài đặt gì.
